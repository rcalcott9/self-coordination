# Self-model vs shared salience

`2026-07-30` · selfcoord_identity

## What it tested

Partner identity (self / same-distribution / different AI / unknown) crossed with stimulus type (focal vs matched-by-construction).

## What it found

Stimulus dominates; identity is small and unresolved. On focal sets every framing is at ceiling. On matched sets (noise, mirror) the self framing beats the unknown baseline by +0.046 in match rate pooled over both n=24 runs (95% CI -0.024 to +0.124, permutation p = 0.10, n = 48 per arm) — positive in both runs and on both stimuli, but underpowered, so **not** the clean null the first pass called it. `a different AI` sits at the baseline (-0.005); `same distribution` is +0.059 but incoherent across stimuli. The self framing also changes the model's vocabulary (37% introspective language vs 0%) without changing its procedure (96%+ salience-hunting in every condition).

`150646` and `154134` are the same model, stimuli and n, differing only in the third
arm, so their `self` and `neutral` cells are pooled to n = 48. `other` and
`shared_dist` exist in one run each and are always contrasted against **that run's own**
`neutral` arm, never the pooled one. Pooling assumes the `self`/`neutral` opener wording
was unchanged between the two runs (they are 35 minutes apart on the same script) — worth
confirming before this goes in a manuscript.

Earlier versions of the figure used `144039` and `154134` only, leaving `150646`
— the only salience-absent `a different AI` arm — out of the analysis entirely.
