# Partner-specific coordination matrix

`2026-08-02` · partner_specific_coordination

## What it tested

Does the self-vs-other confidence gap track the measured, stimulus-specific self-coordination advantage? Builds GG/CC/GC match matrix from the arm-1 choices.

## What it found

inkblot is a GPT-only focal point (self-advantage +0.47); rot is a Claude-only one (+0.12). The rest are shared-focal or flat at chance. Exploratory: elicited under generic framing, not named partners.
